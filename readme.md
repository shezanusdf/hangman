# Hangman

Hangman is a simple terminal based quiz game where the player has to guess the word before the complete image of the hangman is formed.

## Features

- Categories like Birds, Animals, Countries, Fruits and Colors
- random word selection
- ASCII hangman drawing
- Ctrl + C to quit the program

## Functions
- check_win_or_loss() : win/loss detection
- check_letter(letter) : input validation
- take_input() : takes input

## Controls
- Type one letter and enter
- Enter only one alphabet
- Repeated guesses are ignored

## Example
```bash
Category : Animals
_ _ _ _ _
Guess a letter : I
_ I _ _ _
```
## How to run

1. Clone this repo
```bash
git clone https://github.com/shezanusdf/hangman
```

2. Run the game script
```bash
python hangman.py
```
