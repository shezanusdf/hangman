# Hangman

Hangman is a simple terminal based quiz game where the player has to guess the word before the complete image of the hangman is formed.

## Features

- Categories like Birds, Animals, Countries, Fruits and Colors
- check_win_or_loss() checks if the player won and as a result breaks the loop
- check_letter(letter) checks if the letter entered is valid
- take_input() does exactly what its name suggests
- Ctrl + C to quit the program
